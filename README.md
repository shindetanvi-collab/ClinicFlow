# ClinicFlow

ClinicFlow is a medical practice and appointment portal. Patients can browse medical specialties and book appointments, while clinic staff manage bookings from a protected dashboard.

## Features

- Patient view with medical specialties (Cardiology, Pediatrics, General Medicine)
- Appointment booking form
- Passcode-protected staff dashboard
- View appointments and update their status
- Live appointment metrics
- Appointment data saved in the browser using localStorage
- Responsive design

## Built With

- HTML
- Tailwind CSS
- JavaScript
- Lucide icons

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation or server is needed. Appointment data is stored in your browser, so it stays on your device.
